# Dependencies

- [WordPress 6.9+](https://wordpress.org/documentation/wordpress-version/version-6-9/) provides the required WordPress runtime.
- [PHP 8.0+](https://www.php.net/releases/8.0/en.php) provides the required server runtime.
- [WordPress Abilities API](https://developer.wordpress.org/apis/abilities-api/) provides native ability registration and execution.
- [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter) exposes registered WordPress abilities to an authenticated MCP client.
- [MCP Expose Abilities](https://devenia.com/plugins/mcp-expose-abilities/) provides the Devenia MCP transport and base WordPress ability stack.
- [Rank Math SEO](https://wordpress.org/plugins/seo-by-rank-math/) owns the SEO metadata, modules, sitemaps, logs, and redirection data used by this add-on.
